Plain HTML in. A finished website out. No classes.

nss styles every HTML element and recognises common page structures — cards, timelines, tiles, galleries, stat rows, a sidebar — from the HTML alone. Nothing to learn but HTML.

# features

  • Every element: typography, code, tables, media, forms, dialogs.
  • Patterns: write the structure, get the component.
  • Themes: one file of variables; light and dark built in.
  • Tiny: about 7 KB gzipped, zero JavaScript.
